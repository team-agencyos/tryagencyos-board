# TryAgencyOS Migration Board

Live status board for an internal agency consolidation.

**→ https://team-agencyos.github.io/tryagencyos-board/**

This repo exists only to host that page. It is generated — client names, leads and
project links are stripped from this build, so it shows client codes only. The
full-detail board, the register and the phase documentation live in a private repo.

Regenerate with `scripts/build_board.py` in the private repo; a build-time check
fails the build if any identifying detail reaches this version.
